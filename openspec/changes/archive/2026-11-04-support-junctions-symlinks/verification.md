TLC's fingerprint-collision estimate based on actual fingerprints was `.038` (3.8%); its separately reported calculated value was `1.4`. These are limitations of this probabilistic fingerprint-based bounded check. To avoid continued growth on the system disk, a completed checkpoint was copied to another drive, checkpoint metadata was hash-checked, and worker traces in the copy were truncated to their recorded offsets. TLC recovered 402,801,818 states and completed the resumed run in 13h 47min. The original checkpoint was retained locally.

For the recovery investigation, both graph pointer files and worker traces were longer than their saved checkpoint offsets. TLC's recovery code seeks to those offsets without truncating, whereas final liveness checking reads the pointer file to its physical length. The checkpoint copy was truncated only beyond the recorded offsets; the original checkpoint was preserved. This addresses a suspected stale-tail issue but does not establish the exception's cause by itself.
